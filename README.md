<h1 align="center">HR Analytics Dashboard</h1>

<p align="center">
An interactive Power BI dashboard for analyzing employee attrition based on various factors like age, role, education, salary, and more.
</p>

<hr>

<h2>Project Overview</h2>

<p>
This project is a fully interactive HR Analytics Dashboard built using Power BI and basic DAX. It provides deep insights into workforce attrition trends, helping organizations understand where, why, and how attrition occurs—empowering data-driven decisions.
</p>

<hr>

<h2>Key Features</h2>
<ul>
  <li>Attrition analysis by job role, department, and education background</li>
  <li>Age-wise and salary-wise attrition trends</li>
  <li>Dynamic filters by gender, experience, and years in company</li>
  <li>Visual breakdowns by salary slabs and average metrics</li>
  <li>Interactive graphs and charts that respond to user input</li>
  <li>Insightful visuals for HR teams and strategic planning</li>
</ul>

<hr>

<h2>Technologies Used</h2>
<ul>
  <li>Power BI Desktop</li>
  <li>Power Query Editor</li>
  <li>DAX (Data Analysis Expressions)</li>
  <li>Custom Visuals and Interactive Filters</li>
</ul>

<hr>

<h2>How to Use</h2>
<ol>
  <li>Download the <code>.pbix</code> file from this repository.</li>
  <li>Open it using Power BI Desktop.</li>
  <li>Use the interactive visuals and filters to explore attrition data.</li>
</ol>
